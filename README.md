## 🚀 Featured Projects

*A selection of projects that reflect my learning, experimentation, and practical development experience.*

### 1. 🖼️ AI Image Variation & Reconstruction Studio

A Streamlit-powered application for AI-driven image transformation using state-of-the-art diffusion models with quantitative reconstruction analysis.

**Technologies:** Python • Streamlit • PyTorch • Diffusers • SD-Turbo • InstructPix2Pix

- Transform images using SD-Turbo (img2img) or InstructPix2Pix (text-guided editing).
- Side-by-side comparison with MSE, PSNR metrics, and per-pixel difference heatmaps.
- Smart device detection (CUDA / MPS / CPU) with cached model loading.

[![GitHub](https://img.shields.io/badge/VIEW_SOURCE-1E1B4B?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chaturyathukivakam/AI-Image-Variation-and-Reconstruction-Studio)

### 2. 🤖 Generative AI Projects

A comprehensive portfolio spanning GANs, VAEs, Style Transfer, and LLM fine-tuning — covering the full spectrum of modern generative models.

**Technologies:** PyTorch • TensorFlow • HuggingFace Transformers • StyleGAN2 • CycleGAN

- DCGAN training on Fashion-MNIST with loss curve analysis.
- StyleGAN2 latent space exploration with interpolation GIFs.
- Neural Style Transfer vs CycleGAN comparison.
- Mode collapse diagnosis and recovery with label smoothing.
- GPT-2 fine-tuning and text generation with decoding strategy experiments.
- VAE for image compression, reconstruction, and denoising.
- LLM-powered GitHub code explainer using Qwen2.5.
