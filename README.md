### 2. 🖼️ AI Image Variation & Reconstruction Studio
A browser-based studio that leverages HuggingFace diffusion models (SD-Turbo & InstructPix2Pix) for instruction-driven image transformation and quantitative reconstruction benchmarking.

**Technologies:** Python • Streamlit • PyTorch • Diffusers • Safetensors • Pillow

- Dual model pipeline: fast inference via SD-Turbo and text-guided manipulation via InstructPix2Pix.
- Real-time MSE and PSNR (dB) signal quality measurement with normalized per-pixel difference maps.
- Dynamic hardware acceleration with automatic CUDA / MPS / CPU backend binding.

[![View Source](https://img.shields.io/badge/VIEW_SOURCE-0F0A3C?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chaturyathukivakam/AI-Image-Variation-and-Reconstruction-Studio)

### 3. 🤖 Generative AI Laboratory

- Fine-tuning GPT-2 with HuggingFace Trainer and causal language modeling.
